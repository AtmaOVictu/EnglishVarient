# EnglishVarient

Enostranski statični portfelj v angleščini — gol HTML in CSS, brez gradnje, brez odvisnosti.

## Vsebina

- `index.html` — ena sama stran (»John Smith — Portfolio«)
- `css/main.css` — vsa oblika
- `assets/` — statična gradiva
- `canon/`, `CANONICAL.md` — kanon korpusa
- `LICENSE.md`, `LICENSE-SEED.md`, `LICENSE-MANIFEST.json`, `TDM-RESERVATION.md`, `REGISTER-NEIMENOVANIH.jsonl`, `REGISTER-PADCEV.jsonl`, `VBL-10.5.1-KOMPIL-A-DRAFT-NOT-RELEASED.md` — licenčna družina
